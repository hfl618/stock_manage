# 元器件库存管理系统 - 详细使用帮助

【软件简介】
本地化元器件管理工具，支持扫码、批量导入、数据备份，无需联网即可使用。

【核心功能说明】
1. 基础录入：仅需填写「品类、型号规格、封装」3个必填字段，其余字段自动填充默认值；
2. 模糊搜索：支持搜索「品类、型号规格、封装、存放位置」关键词，精准筛选数据；
3. 批量操作：勾选表格左侧复选框，可实现批量编辑/批量删除，提升操作效率；
4. BOM导入：支持粘贴表格/上传Excel（xlsx），可批量指定数量/位置等值，无需映射对应列；
5. 开机自启：开启后程序随电脑启动，后台运行不影响桌面操作；

【启动软件】
双击「元器件库存管理系统.exe」
→ 浏览器自动打开 http://localhost:5000
→ 如果未自动打开，手动输入上述地址

【操作步骤】

❶ 添加单个元器件
点击「添加元器件」按钮
→ 填写品类、型号规格、封装（必填）
→ 供应商、数量、位置等可选填
→ 点击「保存」完成添加

❷ 批量编辑元器件
勾选左侧复选框（可全选或单选）
→ 点击「批量编辑」按钮
→ 填写需要统一修改的字段
→ 点击「保存修改」
→ 仅修改填写字段，留空字段保持原值

❸ 批量删除元器件
勾选需要删除的数据
→ 点击「批量删除」按钮
→ 二次确认后删除
→ 同时删除相关图片、附件和二维码

❹ BOM批量导入（高效方法）
点击「BOM批量导入」按钮
→ 选择「粘贴表格」或「上传Excel」
→ 映射品类、型号、封装3个必填字段
→ 非必填字段可选择「不映射」
→ 在批量指定值区域统一设置（可选）
→ 点击「导入」

❺ 搜索元器件
右上角搜索框输入关键词
→ 点击「搜索」按钮
→ 支持品类/型号/封装/供应商/位置多字段搜索
→ 点击「高级搜索」可多条件组合筛选

❻ 二维码管理
点击顶部「扫码管理」按钮
→ 摄像头扫码：对准二维码自动识别
→ 图片扫码：上传二维码图片识别
→ 批量生成：勾选元器件 → 点击批量生成

【BOM批量指定值使用方法】
1. 点击「BOM批量导入」→ 粘贴/上传表格 → 进入字段映射弹窗；
2. 仅映射3个必填字段，非必填字段可选择「不映射」；
3. 在「批量指定值」区域填写需要统一赋值的内容（如数量100），点击导入即可；
4. 优先级规则：批量指定值 > 表格映射值 > 系统默认值；

【数据管理】
1. 数据备份：系统设置 → 立即备份数据 → 备份文件保存在backup目录
2. 数据恢复：系统设置 → 备份恢复 → 选择备份文件 → 恢复会覆盖当前数据
3. 清理残留：系统设置 → 清理残留文件 → 删除无关联的图片/附件/二维码

【二维码功能】[未上线，扫码不成功]
• 自动生成：添加元器件时自动生成二维码
• 重新生成：编辑页面点击「重新生成」按钮
• 扫码查看：手机扫描二维码可查看元器件详情
• 批量操作：勾选多个元器件 → 批量生成二维码

【Windows专属功能】
1. 开机自启：系统设置 → 开启开机自启 → 需管理员权限
2. 自动备份：定期备份到backup目录
3. 快捷方式：可创建桌面快捷方式和开始菜单项

【局域网访问】
电脑端访问：http://localhost:5000
手机/平板访问：
1. 连接同一WiFi网络
2. 查看电脑IP地址（cmd输入ipconfig）
3. 手机浏览器输入：http://电脑IP:5000
4. 例如：http://192.168.1.100:5000

【注意事项】
1. 批量删除操作不可恢复，请确认后再执行；
2. Excel导入仅支持xlsx格式，xls格式请先转换；
3. 数据库文件为instance/component.db，请勿随意删除；
4. 首次运行会自动创建数据库和目录结构；
5. 杀毒软件可能误报，请添加信任；
6. 不要移动或删除static文件夹；
7. 备份文件建议定期复制到其他位置保存；

【常见问题】
Q：端口5000被占用怎么办？
A：程序会自动尝试5001端口，访问 http://localhost:5001

Q：如何迁移数据到新电脑？
A：复制整个程序目录到新电脑即可，数据都在instance、static目录

Q：忘记备份密码？
A：本系统为本地使用，无需密码，直接访问即可

Q：如何完全卸载？
A：删除程序目录即可，如需保留数据，请先备份instance、static目录

【快捷键提示】

• 快速搜索：Ctrl+F 定位到搜索框
